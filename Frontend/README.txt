# AI-Powered Student Assistant - Starter

## Run the starter
1. Extract the ZIP file.
2. Open the `AI_Student_Assistant_Starter` folder.
3. Double-click `index.html`, or open it with Live Server in VS Code.
4. Try the performance predictor and study assistant.

## Important
This is Phase 1: a frontend prototype. The prediction is a transparent weighted demo formula, not a trained machine-learning model. The assistant is rule-based, not a live generative-AI chatbot. Later phases will add Java Spring Boot, MySQL, and a Python/Scikit-learn model.

## Files
- index.html: page structure
- style.css: design and responsive layout
- script.js: demo interactions
